# fatthreeking's Homebrew Tap

Personal [Homebrew](https://brew.sh) tap for macOS applications and command-line tools by [@fatthreeking](https://github.com/fatthreeking).

## Installation

```sh
brew install --cask fatthreeking/tap/<cask-name>
```

Or tap this repository first:

```sh
brew tap fatthreeking/tap
```

## Available Casks

| Name | Description | Install Command |
| :--- | :--- | :--- |
| **[DockMin](https://github.com/fatthreeking/DockMin)** | Click to minimize windows from the macOS Dock — just like on Windows | `brew install --cask fatthreeking/tap/dockmin` |
